`eeg_motor_trace.json` is generated by `uv run python -m compute.eeg_motor` from the PhysioNet EEG Motor Movement/Imagery Dataset v1.0.0
(volunteers 1-20; Schalk et al. 2004, doi 10.13026/C28G6P, ODC-By 1.0). It holds group averages and one 30 s excerpt (C3/C4) of volunteer 1, run 3. Do not edit by hand.
